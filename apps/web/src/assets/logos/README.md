# Logos des assistants

SVG téléchargés depuis [Lobe Icons](https://github.com/lobehub/lobe-icons),
le 2 octobre 2026 :

- [Codex](https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/codex.svg)
- [Claude Code](https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/claudecode-color.svg)

Les fichiers SVG sont conservés tels que distribués. La licence MIT du projet
source est incluse dans `LICENSE`. Les marques restent la propriété de leurs
détenteurs respectifs (OpenAI et Anthropic).

L’interface utilise ces fichiers locaux comme masques CSS : Codex suit la couleur
du texte du thème, et Claude Code conserve sa couleur terracotta `#D97757`.
